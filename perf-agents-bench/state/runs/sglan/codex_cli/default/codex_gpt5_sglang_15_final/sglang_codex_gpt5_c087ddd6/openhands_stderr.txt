codex
Summary of changes
- Optimized Triton kernels to reduce memory traffic and redundant work.
- Added a focused benchmark to evaluate pre-reorder performance.

Key optimizations
- pre_reorder_triton_kernel
  - Early skip per token: scans the token’s top-k once to exit quickly when no expert falls within [start_expert_id, end_expert_id].
  - Single load, multi-store: loads each hidden block once into registers (float32), then fans out to all matched experts; avoids reloading the same input block for each top-k entry.
  - Precomputed cast: creates an unscaled cast buffer once per block and reuses it when no scaling is needed; only computes scaled cast path when a1_scales_ptr is provided.
  - Alignment hint: applied tl.multiple_of on offsets to help Triton generate aligned vectorized memory ops.

- post_reorder_triton_kernel
  - Removed second “clear” pass: always writes the running sum for each block (zeros if no local expert), eliminating a full extra loop over hidden_size.

Benchmark added
- benchmark/kernels/fused_moe_triton/benchmark_ep_pre_reorder_triton.py
  - Simple harness to warm up and time the pre-reorder kernel across configurable sizes; supports float16/bfloat16/float32.
